# Primum

**Bring things to life without writing code.**
Create *sequences* and *automations* for lights, motors, sensors and sound,
and run them on a Raspberry Pi (and later ESP32 and Arduino) — fully local, no Internet required.

> 🚧 Early development. Nothing to install yet — follow the repo to see it grow.

*Primum* comes from **Primum Mobile**, the outermost sphere of medieval astronomy
that set all the others in motion.

🇪🇸 Plataforma de código abierto para crear secuencias y automatizaciones sobre hardware sin programar.
